# FrontAccounting ERP – Manual Testing

## About the Project

This project is about manual testing of FrontAccounting, an ERP application used for accounting and business-related activities.

I am using the FrontAccounting User Guide and the provided requirements document to understand how different features work and to prepare test cases based on the given requirements.

## Modules Covered

**Sales**
- Sales Quotation Entry
- Sales Order Entry
- Delivery Against Sales Orders
- Invoice Against Delivery Note
- Customer Payment Entry

**Purchases**
- Purchase Order Entry
- Receive Purchase Order Items
- Supplier Invoice Entry
- Supplier Payment Entry

**Items and Inventory**
- Inventory Location Transfers
- Inventory Item Movement Report
- Inventory Item Status Report

## What I Am Testing

- Required field validations
- Valid and invalid input values
- Date and quantity validations
- Price, discount, shipping and tax calculations
- Adding, editing and deleting records
- Stock quantity and availability
- Transaction details and report data
- Error messages and actual results against expected results
